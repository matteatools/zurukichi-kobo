# ズル吉工房 — GitHub Pages 公開用

ツール一覧・タイマー説明ページと「ズル吉タイマー」が入った、インストール不要の静的サイトです。
このファイル一式を用意しただけでは、まだインターネットには公開されません。

## 1. ZIPを展開する（Windows）

1. ZIPファイルをダウンロードします。
2. ZIPを右クリック →「すべて展開」→「展開」。
3. 展開先を開き、`index.html`、`assets`、`timer-intro`、`timer`、`README.md` が並んでいることを確認します。

**アップロードするのはZIPそのものではなく、この中身です。**
`index.html` がリポジトリの最上位に置かれるようにします。

## 2. 新しいリポジトリを作る

1. パソコンでGitHubにログインします。
2. 右上の「＋」→ **New repository**。
3. Repository name に、公開前に決めたリポジトリ名を入力します（例：`zurukichi-tools`）。
4. 無料プランで公開する場合は **Public** を選びます。コードも一般公開されるので、個人情報や秘密のファイルは追加しないでください。
5. **Add a README file** をオンにして、**Create repository**。

※既存のゲーム用リポジトリとは別に作成します。

## 3. ファイルを入れる

1. 作ったリポジトリの **Code** 画面で **Add file → Upload files**。
2. 展開先の `index.html`、`assets` フォルダ、`timer-intro` フォルダ、`timer` フォルダ、`README.md` をまとめてドラッグします。
3. `.nojekyll` が見える場合は、それも追加します（この構成では、なくても表示できます）。
4. 下の **Commit changes** を押します。確認画面が出たら `main` へ保存します。
5. Code画面に `index.html`、`assets`、`timer-intro`、`timer` が直接並んでいればOK。外側のフォルダごと入れないでください。

## 4. GitHub Pagesで公開する

1. リポジトリ上部の **Settings**。
2. 左側の **Pages**。
3. Build and deployment の Source を **Deploy from a branch** にします。
4. Branch は **main**、フォルダは **/(root)** を選択 → **Save**。
5. 公開処理を待ち、Pagesに表示された **Visit site** で開きます。反映に最大10分ほどかかることがあります。

**実際の公開URLはPages画面で確認してください。** そのURLをプロフィールのリンクに設定します。
タイマーに直接つなぐ場合は、トップページで「ズル吉タイマー」を選び、説明ページの「タイマーを使う」を開いて、そのURLをコピーします。

## 5. 公開後の確認

- スマホでツール一覧 → タイマーの説明 →「使う」で本体が開く
- スタート／ストップが動く
- メニューの上から下まで操作できる
- パーティ・速度変更・数字を隠す・途中のお知らせ・時間の増減
- 白黒反転・円の表示切替
- PCでは「投影画面を開く」で別の表示ウィンドウが開く

旧サイトで保存した「途中のお知らせ」の設定は、新しいURLには引き継がれません。
ブラウザのタブを閉じたり、機器がスリープした状態での計時は保証しません。

## 更新するとき

同じリポジトリで **Add file → Upload files** から、修正したファイルを同じ場所へアップロードし、Commit changes。公開URLはそのままです。

## 構成

- `index.html`：ツール一覧
- `timer-intro/index.html`：タイマー説明ページ
- `assets/home.css`：一覧・説明ページのデザイン
- `assets/zurukichi-icon.png`：既存のズル吉アイコン
- `assets/zurukichi-guide.png`：ズル吉の案内イラスト
- `timer/index.html`：ズル吉タイマー
- `timer/projection.html`：投影専用画面
- `timer/` 内のJS・CSS：タイマーの処理とデザイン

外部フォント・広告・アクセス解析・会員登録は使っていません。

## 移植時の変更

タイマーの動作は既存版を維持しています。音声出力先についての補足文言だけを削除しました（音声処理は変更していません）。

## デザイン

白を中心に、オレンジと水色を控えめに使用しています。タイマーへの入口と、機能の簡潔な紹介をまとめたシンプルなサイトです。

## パーティモードの最後の10秒

パーティ書体のタイマーでは、残り10秒から大きな数字でカウントダウンし、1カウントごとに少しずつ大きくなる音で演出します。

## ツールを追加するとき

一覧ページの `tool-catalog` 内に、そのツールのカードを追加します。各カードから専用の説明ページへ、説明ページの「使う」からツール本体へつなぎます。現在はズル吉タイマーだけを掲載しています。

## 紹介内容

トップに「タイマーに5つのズル！」として、漫画の見出しと具体的な使いどころを掲載しています。基本の3ステップ案内は省き、詳しい設定方法は説明ページの折りたたみにまとめました。ロゴと紹介ページのデザインを更新しています。タイマー本体は変更していません。

## オフライン版

説明ページから `downloads/zurukichi-timer-offline.html` を保存できます。PCのChrome／Edgeで直接開ける単一HTMLです。ネット接続、インストール、ローカルサーバーは不要です。投影画面も内蔵しています。Web版と設定は共有されず、自動更新はされません。ファイルの移動・ブラウザー変更・保存制限により設定を保持できない場合があります。

オンライン版のtimer/は変更せず、同じソースからオフライン版を生成しています。タイマー更新時はオフライン版も再生成してアップロードしてください。
